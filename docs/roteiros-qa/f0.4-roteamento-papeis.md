# Roteiro de QA — F0.4 roteamento interno Pro/Flash por papel

Data: 2026-07-22
Escopo: papéis de produto `auto|main|fast`, resolução para allowlist DeepSeek, defaults do
headless e fail-closed na fronteira de produto.
Fora do escopo: heurísticas de auto-effort (14.4), execução de tools, seletor de modelo para o
usuário, multi-provider.

## Critério de pronto

1. `main` resolve para `deepseek-v4-pro` e `fast` para `deepseek-v4-flash`.
2. `auto` (padrão de produto) resolve para Pro no tráfego de codificação/headless.
3. Papel desconhecido, ID arbitrário de modelo e inconsistência `role`+`model` falham fechado.
4. `criarProviderRuntime` com DeepSeek usa `role` (default `auto` → Pro); caminho `fast` existe
   na API interna sem expor endpoint/provider/ID ao usuário.
5. Testes comuns offline; nenhum gate comum carrega chave nem acessa a rede.
6. Documentação e checklist/roadmap atualizados no mesmo incremento.

## Matriz automatizada

| Área | Evidência bloqueante |
|---|---|
| Papéis | `MODEL_ROLES` congelado em `auto|main|fast` |
| Mapeamento | `auto`/`main` → Pro; `fast` → Flash |
| Default | sem `role` → Pro (coding path) |
| Fail-closed | `turbo`, IDs de modelo, null, espaços → `not-configured` |
| Consistência | `role: fast` + `model: pro` rejeitado |
| Runtime CLI | default Pro; `role: "fast"` → Flash; papel inválido sem vazar chave |
| Allowlist | `deepseek-inventado` continua rejeitado no provider |
| Export | `resolveDeepSeekModelForRole` / `resolveDeepSeekProviderModel` no barrel `@codingpro/llm` |

## Exercício da API exportada (offline)

Após o build, a resolução pode ser exercitada sem rede:

```bash
node --input-type=module -e '
import {
  resolveDeepSeekModelForRole,
  resolveDeepSeekProviderModel,
  DEEPSEEK_MODEL_PRO,
  DEEPSEEK_MODEL_FLASH,
} from "./packages/llm/dist/index.mjs";
const assert = (c, m) => { if (!c) throw new Error(m); };
assert(resolveDeepSeekModelForRole("main") === DEEPSEEK_MODEL_PRO, "main");
assert(resolveDeepSeekModelForRole("fast") === DEEPSEEK_MODEL_FLASH, "fast");
assert(resolveDeepSeekModelForRole("auto") === DEEPSEEK_MODEL_PRO, "auto");
assert(resolveDeepSeekProviderModel({}) === DEEPSEEK_MODEL_PRO, "default");
try { resolveDeepSeekModelForRole("turbo"); throw new Error("deveria falhar"); }
catch (e) { assert(e?.code === "not-configured", "fail-closed"); }
console.log("resolve: ok");
'
```
