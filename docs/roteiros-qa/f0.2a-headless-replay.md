# Roteiro de QA — F0.2a headless com replay

## Pré-condições

- Node 24 conforme `.nvmrc` e pnpm 10.34.4.
- Nenhuma chave de API; os passos abaixo não acessam rede.
- A fixture `fixtures/llm/ola.jsonl` é sintética e versionada.

## Gate automatizado

```bash
nvm use
pnpm install --frozen-lockfile
pnpm check
```

Resultado desta rodada: format check, lint, typecheck, 44 testes, cobertura por arquivo, build
dos pacotes e smoke do tarball passaram. O smoke instala o pacote num prefixo temporário e
isola `HOME`, diretórios XDG e ambiente da CLI.

## Headless offline

```bash
CODINGPRO_PROVIDER=replay \
  CODINGPRO_REPLAY_FILE=fixtures/llm/ola.jsonl \
  node packages/cli/dist/index.mjs -p "olá"

CODINGPRO_PROVIDER=replay \
  CODINGPRO_REPLAY_FILE=fixtures/llm/ola.jsonl \
  node packages/cli/dist/index.mjs --prompt "outro prompt"
```

Resultados esperados:

- o primeiro comando transmite `Olá! Como posso ajudar?` e termina com exatamente um newline;
- o segundo falha com código 2 e mensagem segura, pois a requisição não coincide;
- nenhuma variável `DEEPSEEK_API_KEY` é necessária ou consultada;
- interrupção por `SIGINT` usa código 130 sem exibir stack ou causa interna.

## Casos cobertos pela suíte

- deltas de texto transmitidos antes da finalização e raciocínio não exibido;
- fixture inválida, vazia, ausente, com uso negativo ou JSON malformado;
- mismatch não consome turno e replay esgotado falha de forma controlada;
- cancelamento antes/durante o carregamento e durante o stream;
- rejeição de fixture que não seja arquivo regular;
- caminhos com espaço/acento e fixture CRLF;
- erros internos e canários de segredo nunca aparecem em stderr.
