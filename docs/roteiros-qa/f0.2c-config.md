# Roteiro de QA — F0.2c configuração em camadas

## Gate automatizado e offline

```bash
nvm use
pnpm install --frozen-lockfile
env -u CODINGPRO_PROVIDER \
  -u CODINGPRO_REPLAY_FILE \
  -u DEEPSEEK_API_KEY \
  -u OPENAI_API_KEY \
  -u AI_GATEWAY_API_KEY \
  pnpm check
```

Resultado local desta rodada: 118 testes aprovados, cobertura global acima dos thresholds,
typecheck, build e instalação offline do tarball aprovados.

## Precedência exercitada no tarball

O smoke cria `HOME`, projeto e fixtures sintéticas descartáveis e comprova:

1. `~/.codingpro/settings.json` seleciona o replay global.
2. `<cwd>/.codingpro/settings.json` sobrescreve a fixture global.
3. `--provider` e `--replay-file` sobrescrevem ambas.
4. O ambiente E2E não contém chave; mesmo uma regressão de seleção falha antes de acessar rede.
5. O pacote instalado não depende do `node_modules` do workspace.
6. Replay do projeto vence DeepSeek global e projeto tentando DeepSeek falha antes da chave.

## Casos de segurança cobertos

- JSONC com BOM, comentários e trailing comma; versão e schema fechados.
- Duplicatas, campos desconhecidos/proibidos e chaves de prototype rejeitados.
- Projeto não pode selecionar DeepSeek nem usar fixture absoluta/fora do `cwd`.
- Symlink (inclusive no diretório sem `settings.json`), hardlink, arquivo não regular, permissões
  graváveis e arquivo acima de 64 KiB falham.
- Fixture do projeto é aberta com `O_NOFOLLOW`, validada e lida pelo mesmo descriptor; o runtime
  recebe o conteúdo já capturado e não reabre o pathname.
- Configuração malformada nunca é ignorada por uma flag de maior precedência.
- Ausência de arquivos é normal; nenhum arquivo é criado implicitamente.
- Ajuda, versão e prompt vazio continuam sem carregar configuração ou construir provider.
- `DEEPSEEK_API_KEY` é lida somente depois que uma camada confiável seleciona DeepSeek.
- Cancelamento é exercitado antes do I/O, no tratamento de ausência, após a camada de projeto e
  entre a resolução da configuração e a criação do provider.

## Schema v1

```jsonc
{
  "version": 1,
  "provider": "replay",
  "replay": {
    "file": "fixtures/llm/ola.jsonl",
  },
}
```

A configuração global também pode selecionar `deepseek`; a configuração do projeto não pode.
Chaves, endpoints, headers, modelos, interpolação de ambiente, includes, hooks e tools estão fora
do schema e são rejeitados.
