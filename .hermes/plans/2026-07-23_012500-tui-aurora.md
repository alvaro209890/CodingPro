**Objetivo:** Substituir a interface readline atual por uma TUI bonita e fluida usando Ink (React no terminal) com o tema Aurora escuro (esmeralda→ciano→violeta), mantendo 100% da lógica existente intacta.

**Stack:** Ink 5 (React para terminal) + React 19 + theme tokens CSS-like → objetos JS

/** Detecta quantas cores o terminal suporta. */
export function detectarCores(): 16 | 256 | 16777216 {
  const term = process.env.TERM ?? "";
  const colorterm = process.env.COLORTERM ?? "";
  if (colorterm === "truecolor" || colorterm === "24bit") return 16777216;
  if (term.includes("256color")) return 256;
  return 16;
}

**Arquivos:**

**`Spinner.tsx`** — gradiente animado com 3 frames:
```tsx
import React from "react";
import { Text } from "ink";
import { aurora } from "../tema.js";

const FRAMES = ["◜", "◝", "◞", "◟"];
const CORES = aurora.gradiente;

export function Spinner({ texto }: { texto: string }) {
  const [frame, setFrame] = React.useState(0);
  const [corIdx, setCorIdx] = React.useState(0);

  React.useEffect(() => {
    const id = setInterval(() => {
      setFrame((f) => (f + 1) % FRAMES.length);
      setCorIdx((c) => (c + 1) % CORES.length);
    }, 80);
    return () => clearInterval(id);
  }, []);

  return (
    <Text color={CORES[corIdx]}>
      {`${FRAMES[frame]} ${texto}`}
    </Text>
  );
}
```

**`StatusBar.tsx`**:

## Task 3: Componente Timeline — streaming de chat com trilho lateral

**Objetivo:** Criar o componente principal que renderiza mensagens com trilho visual à esquerda.

**Arquivo:** `packages/tui/src/componentes/Timeline.tsx`

**Comportamento:**
- Cada mensagem do usuário começa com `◆` (diamante preenchido)
- Cada resposta do assistente tem um trilho vertical `│` à esquerda
- Deltas de texto aparecem em tempo real (streaming)
- Pensamento (reasoning) aparece colapsado com `●─ Pensando…`
- Ações de tool mostram `●─ Lendo arquivo.ts ✓` com spinner enquanto ativo
- Resultados de tool mostram diff inline (se houver)
- Cores: usuário = branco, assistente = texto normal, tool = muted, erro = vermelho

**API do componente:**
```tsx
<Timeline
  mensagens={historico}
  streaming={textoAtual}
  eventoAtual={evento}
/>
```

Onde `historico` é um array de blocos: `{ tipo: "user" | "agent" | "tool", texto: string, detalhes?: string }`.

**Verificação:** Teste de render com fixture de mensagens.

**Arquivo:** `packages/tui/src/aprovador.tsx`
